# 扩大疾病训练数据版本

2026年11月13日。独立冻结版本包含24,491张疾病图像：训练15,480张、模型验证2,046张、规则开发2,053张、内部及新增留出测试3,470张、ACRIMA外部测试705张、HYGD外部测试737张。

新增图的用途分别为训练5,142张、验证858张、规则开发833张、测试2,237张。修正后的原训练部分为10,338张。通过`origin_cohort`选择`formal_v3`或`expansion_20261113`训练行，各对照实验共享同一验证集。`imaging_domain`明确标识KEH视盘裁切图。

已知患者及已确认照片关联组保持同一用途。PAPILA整来源留作测试，FIVES与Fundus-AVSeg官方测试图保持测试用途，原疾病测试图全部保留。18张关联官方EyeQ测试的原训练及验证图从本版本排除，另排除12张此前已修复的规则开发图。

真实劣质阳性分别保留训练72张、模型验证12张、规则开发12张、测试50张。FIVES以`quality_fives_any_poor_dimension=True`记录条件，MSHF以`quality_overall_official=0`表示差，两来源分别报告。204张辅助疑似图不进入二分类训练。

全部文件哈希与完整RGB解码检查通过；新增图与审计原像素哈希一致。现有质量模型保持冻结，本版本仅用于疾病模型。
