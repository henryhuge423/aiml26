# 2026-11-09 训练准备协议

依据：用户完整说明——先训练青光眼分类模型和 FTHNet 蒸馏的质量模型，为每张图产生 p、q；在验证集上比较疾病预测与真值，分析正确/错误图片在 p–q 空间的分布，选择人工复核灰区边界；边界锁定后应用独立测试集，由实际选中数量产生复核比例。主要对照是另一个经可靠验证的二分类模型按不确定性选取相同数量图片，比较剩余自动结果的错检率和青光眼漏检。本文记录设计与开训门槛，尚无训练结果或确定阈值。

## 已确认的方法与比较目标

1. **产生两种分数。** 模型 A 输出疾病分数 p，质量模型输出 q；先固定疾病分类规则（例如 p≥t_A 判阳性）及分数尺度，再定义错误 e=1[预测标签≠真实标签]。q 表示图像质量，不直接等于疾病判对概率。两个模型可以分别训练；是否共享 backbone 属于后续可选实现实验。
2. **验证集分布分析。** 在相同 p–q 坐标和分箱下绘制全部、正确、错误图片的数量图和局部错误率图；把 FN、FP 分开标记，并显示每格样本数。只看错误点数量会把样本多的区域误当高风险区，不能据稀疏区域的极端比率确定复杂边界。
3. **选择复核边界。** 用 R_A(p,q)=1[f_θ(p,q)≥0] 表示进入灰区；检查灰区同时捕获的错误数和正确数，以及灰区外残留错误/FN。用户所说的“切面”是对边界的直观解释，具体函数未指定为直线、平面或单调曲线。候选函数与复杂度控制需要预先记录。
4. **复核比例由边界产生。** 在验证数据上权衡残余错误、漏检和复核工作量，再选择 θ；不预先强制复核率为 5%、10% 或 20%。选择目标仍须明确，例如错误/漏检代价与人工复核代价的权衡或验证集 Pareto 曲线上的事先约定选择规则，否则“全部复核”会成为没有实际价值的最优解。具体代价和函数族尚未确定。
5. **锁定后独立测试。** 冻结 A、质量模型、预处理、校准、t_A 和 θ。新图片只凭 p、q 判定是否进入灰区；灰区外保留 A 的原始二分类结果。不能用测试真值重新画边界、挑模型或改变分类阈值。
6. **主要比较两套方案。** 在查看最终测试结果之前，按验证集表现和可核查依据选定对照 B；记录其权重版本、训练来源、预处理、标签定义、独立验证证据和锁定的分类阈值 t_B，核查其与测试数据的重叠。B 的选择不能依据本项目测试表现。两套模型必须在同一个有可靠疾病真值、目标定义一致的测试队列评估。
7. **测试集匹配数量。** 对 N 张测试图先计算 k=ΣR_A(p_i,q_i)，r=k/N。B 按预先指定的不确定性指标排序，恰好复核 top-k；排序不能使用真值或事后观察的错误。平分用事先固定、与标签无关的样本 ID/种子规则打破。A 的边界固定，B 的 top-k 数量随 A 的实际工作量产生；这是一项测试队列上的同复核量比较，B 的最终分数截点不是验证集预先固定的部署阈值。这种数量匹配不使用测试标签，本身不等于测试标签泄漏。
8. **区分结论范围。** A+质量边界 对 B+不确定性 是用户指定的主要完整方案比较，能评价哪套方案在同等复核量下保留更可靠的自动结果。若 A≠B，差异同时包含分类器与分流规则贡献；不能单独归因于质量信息。建议补充 A+不确定性 top-k 消融以隔离分流规则贡献，random、quality-only 等可选；这些建议不替代主要比较，也不是用户已确认的额外实验。

正式实现前，还须预先写清边界候选、选择准则、不确定性定义和并列处理。二分类预测熵或距 0.5 的距离是可选排序指标，具体采用哪一个尚未锁定。模型选择/早停与边界选择应尽量使用分开的开发子集，或采用患者/关联组交叉拟合；最终测试始终独立。

## 训练数据纳入规则

疾病头使用**标签可信、目标模态正确、视盘可判读且覆盖质量变化**的眼底图。不能只保留最高全图质量，也不能把所有文件夹标签直接视为可靠真值。

| 图像情形 | 疾病监督 | 质量训练/分流评估 |
|---|---|---|
| 清晰、视盘完整、标签可靠 | 保留 | 保留 |
| 中等曝光/色偏/清晰度，但视盘可判读 | 保留，记录质量层 | 保留 |
| 视盘中心裁剪，视盘仍完整 | 可保留；标记裁剪域 | 不能自动视作低质，检查教师域差异 |
| 严重模糊、视盘缺失、不可判读 | 暂不进入常规疾病损失；有可靠独立诊断者可另做预注册敏感性实验 | 保留为质量/拒识样本，不能因低质量从质量数据中删除 |
| 非眼底、网页拼图、答案文字、错误/冲突标签 | 排除或隔离待复核 | 可另作 OOD 测试，不能伪装为正常眼底质量样本 |
| 增强、重编码、裁剪或双眼/同人相关图 | 先建立组，再分集合 | 两个任务使用同一组级隔离规则 |

FIQS 的低 MOS/reject 是有效质量监督；HYGD 的 Quality Score 来自 FundusQ-Net，不能冒充人工 MOS 或 FTHNet 输出。视觉抽样和通用清晰度指标均不是眼科专家可判读标签。

## 标签、来源和划分

1. AIROGS 保留 RG/NRG 的“可转诊性”定义，NRG 不是健康眼。ACRIMA/EyeAugmented/Kaggle 的 glaucoma/normal 与 HYGD 的 GON+/GON− 保留独立 target_definition；广泛数据不能以抹平标签语义为代价。
2. 当前冻结方向：AIROGS为主要开发来源，ODIR逐眼明确标签和去重后的Kaggle加入多来源代理监督；EyeAugmented因原图家族不可恢复，整来源二分类候选暂隔离。ACRIMA、HYGD整体保留外部来源测试。来源审计未发现不等于证明无患者重叠，按冻结清单保留限制并分来源评价。
3. ODIR 读取逐眼 workbook 的 filename、Diagnostic_Keywords 和 orig_id；不将患者 G 标志赋给两只眼，不按辅助 full_df.csv 的 path 读图。不明/其他眼病不自动标成阴性。
4. HYGD 按 Patient，ODIR 按核对后的 orig_id/双眼组；其他来源患者 ID 缺失时如实记 UNKNOWN。不得把 AIROGS 的 id 当患者 ID。先建立跨来源原图家族与重复连接组，再划分。
5. 建议分离训练、早停验证、校准/策略开发、最终测试。数据不足时用分组交叉拟合，不能一边选模型一边在同一测试集调阈值。
6. FIQS 两种分辨率同名文件属于同一图。公开 FTHNet checkpoint 的实际训练患者/折信息未证实，不能随意重切 FIQS 后称其为教师未见的质量测试；可报告蒸馏一致性，但独立人工质量泛化需另有未见、专家标注的队列。
7. 蒸馏只能读取疾病训练/开发允许的图，禁止用最终疾病测试图生成训练伪标签。EyeQ 原图不齐时不把它计入本轮可用训练数。

## 实验顺序

1. **先完成教师复现和数据冻结。** 用固定输入/种子复现 FTHNet 原配置，确认 checkpoint 的 `params`/`params_ema` 选择，保存权重哈希、预处理、原始输出、数据版本。作者默认使用 `params`；输入及归一化详见本地原配置，不凭论文文字重写。
2. **训练疾病 baseline。** 在所有符合上述条件的可靠标注图上做 BCEWithLogits，按来源和类别检查采样比例；“仅高质量”和“包含所有可判读质量”的两组实验共用相同测试集、组级划分和训练预算。分类模型的差异与分流策略的差异分开报告。
3. **蒸馏质量头。** 教师冻结并缓存允许数据的输出。连续分数使用回归蒸馏（如 Huber），不直接套多类别温度 KL。原始 MOS 范围和教师归一化输出同时记录；不能把三等级 EyeQ 强行当成同尺度 MOS。人工 MOS 监督与教师伪标签须分列来源。
4. **形成 p、q 输出流程。** 先保证分别训练的疾病模型和蒸馏质量模型可复现地对同一图片输出 p、q。共享 backbone 和联合损失是可选后续实验；若采用则记录两个任务的 loss mask，缺失标签不填成 0，并检查联合训练是否使任一任务退化。
5. **验证集错误分布和区域选择。** 按上述已确认方法绘图并选择边界，同时检查正确样本被送复核的工作量。先固定校准和疾病分类阈值，再构造错误标签、选择边界；不预设固定复核比例。
6. **锁定后测试。** 固定模型、疾病分类阈值和灰区边界，在独立测试集获得实际 k，再让锁定的对照模型按不确定性选出 top-k。主要结果按用户指定的完整方案比较呈现，同分类器消融另列建议。

## 评价与开训门槛

- 主要指标为灰区外错检率：对方案 j，E_j=Σ(1−R_ji)·1[ŷ_ji≠y_i]，错检率=E_j/(N−k)。两套方案复核数均为 k，自动处理数均为 N−k，但剩余图像可以不同。这里“错检率”包括 FP 和 FN，不能只计算假阳性。
- 单列自动结果中的青光眼漏检 FN_auto,j=Σ(1−R_ji)·1[y_i=1 且 ŷ_ji=0]，并报告 FN_auto,j/全部真实阳性数；另列自动子集敏感度及其分母，避免混淆。报告实际复核率 k/N、覆盖率 (N−k)/N、灰区捕获错误/正确数，以及零复核时两分类器的原始性能。
- 在同一患者/关联组重采样下对完整比较流程计算成对置信区间；每次重采样重新计算固定边界的 k 并执行 B 的 top-k，不能重新拟合边界。k=0 时比较全部自动结果；k=N 时错检率分母为零，记为未定义，不填 0。复核图片不能直接当作已被正确诊断；当前主要比较只衡量剩余自动结果。
- 保留包含低质、难例及 OOD 的完整筛查流程评估；疾病诊断指标的分母限定为有可靠疾病真值的适用样本。无疾病真值的不可判读图单独评价拒识，不能当阴性。人工复核不自动等于纠错，若模拟完美专家须说明。
- 教师前向、GPU、预处理一致性；标签/重复/患者组清单；冻结划分；质量复核结果；训练脚本及一小批真实图像的 forward/backward/checkpoint-resume 检查全部通过后，才启动正式长训练。
- 本轮已完成训练入口及真实数据准备验证，正式20epoch研究训练未启动；尚无正式疾病性能、选定的可靠B模型或风险边界。训练准备结论由实际验证和冻结产物支持，不能用小批次检查点替代研究结果。
