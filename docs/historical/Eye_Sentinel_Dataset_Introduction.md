# Eye Sentinel 数据集与实验方案

## 1. 项目方向与数据选择

Eye Sentinel 用于社区青光眼筛查。系统先检查眼底照片是否清楚，提示工作人员重拍质量较差的图像，再估计青光眼概率，将难以判断的图片交给专家。我们希望在相同的专家复核额度下，减少被判为筛查阴性的青光眼病例。

本次任务是区分青光眼与正常眼底，Wide-Field 和 FrontofEyeDx 留作后续研究。图像数量来自 2026-10-22 的清理后清单，方案更新于 2026-10-23。

| 来源 | 青光眼 | 正常眼底 | 本次安排 |
|---|---:|---:|---|
| EyeAugmented | 2,325 | 2,615 | 用于开发，整理原图与增强版本 |
| Kaggle 眼病分类子集 | 1,005 | 1,074 | 用于开发，按来源与相关图片分组 |
| ACRIMA | 396 | 309 | 整套留作最终测试 |
| 合计 | 3,726 | 3,998 | 7,724 张候选图像 |

上述合计包含 ACRIMA 的 705 张图。留出 ACRIMA 后，**7,019 张**图像用于开发：青光眼 3,330 张、正常眼底 3,689 张。完成相关图片分组和标签核对后，记录各集合的最终数量。

ODIR 另有 3,500 位患者的 7,000 张双眼照片，每位患者对应一个 `orig_id`。扩展实验将利用这些编号按患者分组，并汇总双眼的筛查结果。

数据工作区共有 34,471 张去重图像：Fundoscopy 27,242 张、Wide-Field 4,886 张、FrontofEyeDx 2,321 张，以及单独存放、等待标签复核的 22 张图。

## 2. 标签、来源和分组

从 Fundoscopy 的 `Glaucoma` 与 `Normal Retina` 目录提取图像，沿用整理后的标签。逐张检查拍摄类型、视盘是否清楚、画面中是否出现病名，以及标签是否一致，并记录图片的处理结果。

| 字段 | 用途 |
|---|---|
| image_id、相对路径、SHA-256 | 定位文件与识别完全相同的图像 |
| source_collection、原目录标签、统一标签 | 追溯来源，建立二分类标签 |
| patient_id、orig_id、eye | 对有病例标识的来源按患者分组 |
| parent_image_id、group_id | 合并增强图、裁切图、压缩版本及同病例图版 |
| split、标签核对记录、质量记录 | 固定实验用途，解释样本处理过程 |

整理 EyeAugmented 时，先找出原图及其增强版本，再结合文件名、相似图检索和人工查看，为相关图片分配同一个 group_id。每组图片一起进入训练、验证或测试集。

ODIR 按 orig_id 将左右眼放在同一组，结合疾病字段和左右眼诊断关键词整理每只眼的标签。汇总患者结果时，采用双眼中更需要干预的一侧。其他来源按已有病例编号、原图及其衍生版本分组。

在所有候选图片中查找跨来源的相似版本，将相关图像放进同一个集合。ACRIMA 及其关联版本一起留作最终测试。模型读取图像像素，文件路径和文字说明用于查找图片、核对标签。

**数据划分：** 按图像组将开发数据分为训练、验证和内部测试集，比例约为 70% / 15% / 15%，兼顾类别和来源分布。验证集再分成两部分，分别用于概率校准和分流参数选择。清单记录随机种子，以及每个集合中各来源、各类别的实际数量。

## 3. 质量评估与分流方法

**质量检查。** 在眼底有效区域内计算 Laplacian 方差、RMS 对比度、过暗和过曝像素比例。统一视野尺寸，质量分数 Q 归一化到 0–1。质量阈值和归一化参数由开发数据确定。

照片质量较差时，界面显示“画面偏暗”“对焦不清”等提示，引导工作人员重拍。系统重新检查新照片，将重拍后仍无法看清的图片交给人工评估。

**青光眼预测。** 使用预训练 MobileNetV3-Small 识别青光眼与正常眼底，初始输入尺寸为 224 × 224。在校准集上拟合温度参数 T，得到校准后的青光眼概率 p，再用 ECE、Brier score 和可靠性图比较校准效果。

**专家复核排序。** 使用归一化二元预测熵表示不确定度：

U = −[p ln(p) + (1−p) ln(1−p)] / ln(2)

综合分数为 **S = w × U + (1−w) × (1−Q)**。权重 w、筛查阳性阈值 t 和质量阈值由策略开发集选择，最终测试固定使用这些参数。S 表示复核优先程度，p 用于判断筛查阳性或阴性。

| 输出 | 处理方式 |
|---|---|
| 黄色：质量不足，现场可重拍 | 显示具体原因，再次采集并评估 |
| 绿色：质量合格、p < t、未进入复核队列 | 生成筛查阴性记录，附常规随访提示 |
| 红色：p ≥ t、进入复核队列或持续无法判读 | 生成转诊/复核记录，附原图、概率与质量原因 |

主实验每一百张图选十张交给专家复核，其余图片按概率阈值给出筛查结果。分别记录筛查阳性转诊和专家复核人数，按患者去重后统计总转诊量，以及超过接诊容量的待处理人数。

## 4. 实验设计

我们比较三种选图方法，观察加入图像质量信息后，能多找出多少原本会漏掉的青光眼。主要实验每一百张图选十张复核，同时测试选五张和二十张的情况。

| 策略 | 复核排序依据 |
|---|---|
| 随机复核 | 固定随机种子抽样，多次重复 |
| 标准 AI | 校准后的预测熵 U |
| 质量感知 AI | 综合分数 S |
| 消融对照 | 仅使用质量分数 1−Q |

各方法使用相同的重拍规则、分类器、校准参数和筛查阈值，比较不同复核排序的效果。复核率按重拍结束后进入评估的图片数计算。另比较加入质量检查前后的整体表现，按最初输入的人数统计重拍、最终无法判读、筛查阴性和转诊情况。

**质量扰动。** 在固定测试图像上生成以下版本，保留原始标签及 parent_image_id，逐项和组合测试。参数在测试前固定。

| 扰动 | 参数 |
|---|---|
| 高斯模糊 | 224 px 标准视野下 σ = 0.5 / 1.0 / 2.0 |
| 曝光偏移 | 亮度增益 0.6 / 0.8 / 1.2 / 1.5，另加径向暗角 |
| 对比度压缩 | 围绕有效区域均值缩放至 0.8 / 0.6 / 0.4 |

分别报告原图及各退化版本的结果，并对同一张图的不同版本作配对比较。重拍模拟使用对应原图作为恢复清晰后的输入，展示图像质量完全恢复时的效果。后续现场采集实验记录实际重拍成功率。

**跨来源测试与统计。** 用固定参数测试 ACRIMA 的全部 705 张图，并按来源和退化强度整理结果。内部测试按相关图像组、ODIR 按患者进行 bootstrap 重采样，报告样本数、指标的分子和分母，以及 95% 置信区间。

## 5. 评价指标与目标

最关心的结果是有多少青光眼被判为筛查阴性。同时统计筛查阴性占全部输入的比例，观察减少漏诊需要多少人工处理。目标是降低漏诊率，并使阴性预测值 NPV 超过 98%。各项结果附实测值和置信区间。

| 指标 | 定义与用途 |
|---|---|
| 放行组漏诊率 | 筛查阴性中的真青光眼数 ÷ 全部真青光眼数 |
| 阴性预测值 NPV | 筛查阴性中的真正常数 ÷ 全部筛查阴性数 |
| 阴性覆盖率 | 筛查阴性数 ÷ 全部输入数 |
| 青光眼复核捕获率 | 复核队列中的真青光眼数 ÷ 全部真青光眼数 |
| 青光眼复核精确率 | 复核队列中的真青光眼数 ÷ 全部复核数 |
| 错误捕获率 | 复核队列中的原分类错误数 ÷ 全部原分类错误数 |
| 留存组表现 | 去除复核队列后的准确率、AUC、敏感度和特异度，附类别数量 |
| 工作负荷 | 重拍率、持续无法判读率、复核率、阳性转诊率、患者去重后的总转诊率与容量溢出数 |

主分析列出测试集中的青光眼比例。再按 2%、5%、10% 的患病率重新加权，使用相同的分类结果计算 NPV，观察不同筛查人群下的表现。

从需要人工处理的图片中抽取一部分，记录视盘是否清楚、图像有哪些质量问题、是否有值得复核的病变。整理这些记录，统计专家复核中有多少图片提供了有效的病变信息。

**工程目标：** 笔记本 CPU 上单图全流程推断 <200 ms，进程峰值内存 <500 MB。固定输入尺寸、线程数和硬件，预热后重复计时，记录中位数、P95、批次耗时及模型大小。现场采集与重拍耗时另行记录。

**预期图表：** 复核预算与漏诊率曲线、预算与错误捕获率曲线、NPV 与阴性覆盖率、分来源及退化强度结果、可靠性图、CPU 时间与内存。

## 6. 离线演示与交付

工作人员可以一次导入一批图片，查看原图、青光眼概率、质量分数和处理原因。黄色列表显示重拍提示，导入新照片后重新评估。绿色列表生成筛查阴性记录，红色列表生成转诊或专家复核记录。

转诊记录附上原图、样本或患者编号、转诊原因和图像质量问题。完成视盘定位和核对后，将视盘局部图与完整眼底图一起展示。每位患者的记录包含初次拍摄、重拍、筛查结果和后续处理情况。

| 交付内容 | 具体材料 |
|---|---|
| 数据清单 | 标签对应、来源、图像家族、患者分组、固定划分及质量记录 |
| 算法代码 | IQA 算子、MobileNetV3-Small、温度缩放、排序与分流函数 |
| 实验报告 | 方法比较、质量检查消融、ACRIMA 测试、复核预算曲线及运行性能 |
| 离线 Demo | 批次导入、重拍反馈、筛查结果和转诊记录导出 |

四位成员分别牵头数据整理、模型与校准、实验评估、演示与报告，并交叉核对数据划分和结果。项目成员：Xinhao Jin、Zihan Fan、Zheng Jian、Barzin Badiee。

项目将比较各方法在相同复核额度下的漏诊情况，并结合重拍率、阴性结果比例和总转诊量，评价整个筛查流程。
