# 下一步实验与评价

2026 年 11 月 13 日更新 · [English](next-steps.en.md)

本轮数据整合、四组训练和配对分析已完成。扩展数据改善了新增来源表现，原来源采样次数减少且 AIROGS／ODIR 的排序下降；退化收益主要出现在合成失焦。下一轮围绕这些已观察到的差异设计对照。

| 工作 | 具体安排 | 判断依据 |
|---|---|---|
| 区分数据组成与采样作用 | 原数据对照，加四个扩展组：当前采样／65% 原数据配额，分别使用无退化／50% 混合退化。 | 比较主要来源 AUROC、原图概率误差、实际采样次数和独立图像覆盖。 |
| 增加重复实验与预算 | 三个共同随机种子、各 2,400 次更新，保存每 300 次更新的权重与预测。 | 分别报告病例抽样区间与种子间差异；比较第 1,200 与 2,400 次更新。 |
| 改进模型选择 | 预先指定 AIROGS、ODIR、Kaggle、LAG、KEH 的等权 AUROC 平均值，其他来源单列。 | 同时检查原三来源平均值及来源阈值表现，减少极小验证来源的影响。 |
| 分解退化方法 | 相同应用概率、采样序列和预算下比较仅失焦与当前混合退化。 | 固定验证阈值的漏诊／误报、原图 AUROC、Brier 分数及真实低质量表现。 |
| 补充真实质量病例 | 增加相同来源的真实低质量阴性病例，按来源、质量和类别分层。 | 在阳性检出之外估计误报，并检查质量标记与疾病标签的相关性。 |

## 完成项目主要比较

1. 在模型验证数据上选择疾病模型 A、比较模型 B 和质量模型，记录预处理、权重、分类阈值及所需校准。
2. 在规则开发数据上分析疾病分数与质量分数的联合分布，分别展示正确、错误、漏诊和误报，记录每个区域的病例数。
3. 比较有限数量的复核规则，以复核工作量、残余错误和漏诊为依据选择边界；需要校准或反复选择时采用分组子集或交叉拟合。
4. 固定权重、分类阈值、复核边界、B 的不确定性排序及并列规则，再评价保留测试集。A 选出的实际复核数为 k，B 按不确定性复核同样 k 张。
5. 分来源和质量层报告复核数量、剩余自动结果的错误率与阳性漏诊，按患者或关联组计算配对区间。
