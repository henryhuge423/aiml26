# Proposal-1106 审查与建议

**后续澄清：** 本文保留历史审查。用户随后确认主要实验为“验证集错误/正确 p–q 分布选灰区 → 固定边界测试得到实际复核数 k → 可靠对照模型按不确定性 top-k 匹配数量”。见 [当前训练协议](TRAINING-PROTOCOL-1109.md)。以下第 1、2 点中的主要/次要实验定位是历史建议，不再代表当前已确认方案；不同分类器的归因限制和测试 top-k 的队列依赖性仍需如实说明。

审查日期：2026-11-07。依据 [原始 proposal](../proposal-1106.pdf)；以下为建议，未替团队修改或批准原提案。目标是验证质量信息能否在相同人工复核负担下减少自动处理图像中的错误，而非证明系统已可临床使用。

## 优先解决的问题

1. **比较混杂分类器和分流策略。** 提案另选表现好的分类模型作 uncertainty baseline，即使结果不同也不能归因于质量信息。主要比较应使用同一分类器、同一预测和阈值，只改变复核规则：不确定度、质量加不确定度、质量单独及随机。不同分类器作为次要实验。
2. **测试集匹配复核率存在解释限制。** 固定边界产生复核率，再在测试集按分数取同等数量，是描述性、成对的容量匹配，但 baseline 阈值依赖测试集分布，不能称作完全预先固定的部署策略。同时在验证集确定相同目标容量及阈值，锁定测试集报告实际复核率和风险—覆盖率曲线；明确平分数处理和零覆盖情况。测试匹配结果单列探索性分析。
3. **边界没有具体形式及防过拟合方案。** 预先确定有限候选（如简单 p、q 分箱或低复杂度逻辑回归）；分开分类器训练、校准与边界选择，按患者/来源分组交叉拟合；选择目标、容量约束和阈值后锁定。q 的方向、范围和 EyeQ 三类别到标量的转换须先定义，不能假设与 FQS MOS 等价。分类阈值也须独立于最终测试集固定。
4. **标签和数据清单口径不一致。** 10,747 是原始单标签统计（含 ODIR 200+2,816）；1,124 对的筛选口径是 2,248 只眼，两者不能相加或替换。阳性对另一只眼可能有其他疾病，不能强行标成青光眼或正常；明确排除、保留未标注还是建立独立任务，并重算最终单眼数。旧版清理后计数不同，不能把原始路径数当作当前独立样本数。补充四张须核验标签和重复。
5. **独立性尚未建立。** EyeAugmented 含衍生图，其他来源也可能互相复制、裁剪或重编码；按患者、双眼及原图家族分组，并跨来源做精确和近重复审计后再划分。ODIR 按 orig_id；HYGD 按 Patient（288 人、747 图）。EyeQ 与 AIROGS 均涉及 EyePACS，不能仅凭名称判断是否重叠：核对原始 ID、元数据和图像相似性，隔离质量训练与测试的重叠患者/图像。无法排除时不能称严格独立。
6. **任务与标签不能简单合并。** AIROGS 为 referable / non-referable glaucoma，HYGD 为 GON+ / GON−，本地数据为 glaucoma / normal；阴性定义、判定方式和人群不同。保留原标签及映射，确认可比性，按来源单独报告；不要把 NRG 当成已证实的正常眼底。HYGD 拟微调时需另留未用于训练、调参或选择的患者/来源，或将 HYGD 整体用于外部测试，两种用途不能混用。
7. **评价必须明确分母。** 主指标可设为未复核图像错误率，附错误数/未复核数、复核率和覆盖率；同时报告未复核假阴性数、全部真实阳性中的漏诊比例、敏感度、特异度和置信区间。总体及各来源/质量层报告，按患者或相关图像组配对 bootstrap。复核并不自动等于纠正：模拟完美专家时明确标注假设，真实人工表现留待验证。
8. **外部有效性和数据质量限制。** 文件夹标签未必经临床核验；筛选可能排除复杂疾病；样本类别比例与实际患病率不同，不能直接推断人群 NPV、工作量或临床收益。检查烧录文字、诊断标记和来源捷径；质量模型需独立质量标注验证，模型输出不等于人工真值。
9. **AIROGS 数量写错了单位。** 下载的 v4 中每个类别各有训练 4,000、验证 385、测试 385 张；总计分别为 8,000、770、770（9,540 张）。提案所写 4,000、384、384 不是三个集合的总数。来源的预分割是否满足患者级独立性仍需核查。

## 建议的最小执行顺序

1. 冻结纳入规则、目标标签和来源级清单；核验来源、重复、患者/增强家族及质量模型与测试重叠。
2. 预留不参与训练和选择的患者级内部测试，以及可行时独立来源外部测试；记录各集合患者数、图像数、类别和来源。
3. 用训练集训练 EfficientNet-B0 和质量模型；只用开发数据校准并选择有限边界候选；固定种子、超参数、阈值和模型。
4. 在锁定测试上比较同一分类器的策略，主要报告验证集预设策略和风险—覆盖率曲线；再报告测试观察复核率匹配的探索性结果及分组置信区间。
5. 记录来源、协议、许可、失败和限制；项目当前为研究原型，不作诊断或部署声明。

## 待团队决定

- 主要目标是总体自动错误率还是青光眼假阴性；是否设定固定复核容量及可接受漏诊约束？
- HYGD 用于微调还是完整外部测试？质量模型选择 EyeQ、FQS 或分阶段比较？
- 其他疾病的 ODIR 同伴眼和各来源标签如何处理？如何满足患者级分组？
- 如何确保独立质量训练数据与最终测试无重叠，及如何取得 EyePACS 原图？
